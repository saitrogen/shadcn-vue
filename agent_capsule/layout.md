# Layout Components

## AspectRatio
A container that maintains a specific aspect ratio.

**Props:**
* `ratio`: The aspect ratio of the container.
* `as`: The HTML element to render as.

## Resizable
A component that allows for resizing panels.

**Components:**
* `ResizablePanelGroup`: The main container for the resizable panels.
* `ResizablePanel`: A single panel within the group.
* `ResizableHandle`: The handle to drag to resize the panels.

**Props:**
* `direction`: The orientation of the panels.
* `withHandle`: Whether to show a handle with a grip icon.

## Separator
A visual separator between elements.

**Props:**
* `orientation`: The orientation of the separator.
* `decorative`: Whether the separator is decorative or not.
