# Feedback Components

## Alert
Displays a callout for user attention.

**Components:**
* `Alert`: The main container for the alert.
* `AlertTitle`: The title of the alert.
* `AlertDescription`: The description of the alert.

**Props:**
* `variant`: The visual style of the alert.

**Variants:**
* `default`
* `destructive`

## Progress
A progress bar for displaying the progress of a task.

**Props:**
* `modelValue`: The current value of the progress bar.
* `max`: The maximum value of the progress bar.

## Skeleton
A placeholder for content that is loading.

## Toaster (Sonner)
A toast component for displaying notifications.
