# Overlay Components

## AlertDialog
A modal dialog that interrupts the user with important content and expects a response.

**Components:**
* `AlertDialog`: The main container for the alert dialog.
* `AlertDialogTrigger`: The button that opens the alert dialog.
* `AlertDialogContent`: The content of the alert dialog.
* `AlertDialogHeader`: The header of the alert dialog.
* `AlertDialogTitle`: The title of the alert dialog.
* `AlertDialogDescription`: The description of the alert dialog.
* `AlertDialogFooter`: The footer of the alert dialog.
* `AlertDialogAction`: The action button of the alert dialog.
* `AlertDialogCancel`: The cancel button of the alert dialog.

## Dialog
A window overlaid on either the primary window or another dialog window, rendering the content underneath inert.

**Components:**
* `Dialog`: The main container for the dialog.
* `DialogTrigger`: The button that opens the dialog.
* `DialogContent`: The content of the dialog.
* `DialogHeader`: The header of the dialog.
* `DialogTitle`: The title of the dialog.
* `DialogDescription`: The description of the dialog.
* `DialogFooter`: The footer of the dialog.
* `DialogClose`: The button that closes the dialog.

## Drawer
A drawer that slides in from the side of the screen.

**Components:**
* `Drawer`: The main container for the drawer.
* `DrawerTrigger`: The button that opens the drawer.
* `DrawerContent`: The content of the drawer.
* `DrawerHeader`: The header of the drawer.
* `DrawerTitle`: The title of the drawer.
* `DrawerDescription`: The description of the drawer.
* `DrawerFooter`: The footer of the drawer.
* `DrawerClose`: The button that closes the drawer.

## HoverCard
A popup that displays information related to an element when the element is hovered over.

**Components:**
* `HoverCard`: The main container for the hover card.
* `HoverCardTrigger`: The trigger that opens the hover card.
* `HoverCardContent`: The content of the hover card.

**Props:**
* `openDelay`: The delay in milliseconds before the hover card appears.
* `closeDelay`: The delay in milliseconds before the hover card disappears.

## Popover
A pop-up that displays information related to an element when the element is clicked.

**Components:**
* `Popover`: The main container for the popover.
* `PopoverTrigger`: The trigger that opens the popover.
* `PopoverContent`: The content of the popover.

**Props:**
* `open`: Whether the popover is open or not.
* `defaultOpen`: Whether the popover is open by default or not.

## Sheet
A sheet that slides in from the side of the screen.

**Components:**
* `Sheet`: The main container for the sheet.
* `SheetTrigger`: The button that opens the sheet.
* `SheetContent`: The content of the sheet.
* `SheetHeader`: The header of the sheet.
* `SheetTitle`: The title of the sheet.
* `SheetDescription`: The description of the sheet.
* `SheetFooter`: The footer of the sheet.
* `SheetClose`: The button that closes the sheet.

**Props:**
* `side`: The side from which the sheet will slide in.
